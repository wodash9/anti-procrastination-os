# Sistema Operativo Anti-Procrastinación

Página one-page estática para convertir demasiados proyectos y procrastinación en un sistema de decisión y ejecución.

## Qué incluye

- Diagnóstico de dispersión.
- Matriz interactiva de decisión de proyectos.
- Límite WIP recomendado.
- Técnicas por tipo de bloqueo.
- Protocolo de emergencia de 25 minutos.
- Roadmap de 7 días.
- Fuentes de respaldo.

## Ejecutar localmente

```bash
python3 -m http.server 4173
# abrir http://127.0.0.1:4173/
```

## Verificación esperada

- La página debe cargar sin errores de consola.
- La calculadora debe actualizar la puntuación y decisión al cambiar selectores.
- Las pestañas de bloqueos deben cambiar contenido.
- No debe haber overflow horizontal en móvil.
